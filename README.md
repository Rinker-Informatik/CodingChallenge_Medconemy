# Dateiaustausch – Beispielprojekt

Dieses Beispielprojekt entwickelt eine Webanwendung für den Dateiaustausch zwischen internen und externen Nutzern. Das Backend liegt unter `src/backend`. Die Angular-Oberfläche mit Spartan UI liegt unter `src/ui`. Das Backend ist eine erste lokale Demonstration, keine produktionsreife Anwendung.

Die Backend-Demo verwendet TypeScript, Node.js und Express, PostgreSQL, S3-kompatiblen Speicher und Docker Compose. Anleitungen, API und bekannte Einschränkungen stehen in der [Backend-Dokumentation](src/backend/README.md).

Der [UI-Startleitfaden](src/ui/README.md) beschreibt den lokalen Compose-Start, die Bearbeitung von DOCX und XLSX in ONLYOFFICE und die Browser-Tests.
